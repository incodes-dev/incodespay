# IncodesPay

Reusable multi-gateway payment SDK for Next.js and React apps.

## Supported Gateways

* Razorpay
* Stripe
* PayPal
* Paystack
* Flutterwave
* Cashfree

## Installation

```bash
npm install github:YOUR_USERNAME/incodespay
```

## Usage

```ts
import { startPayment } from "incodespay";
```
